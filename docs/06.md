# Lanjutan

!!! question "Tantangan"
    - Sampai di sini anda sudah berhasil membuat format dasar Front-end Aplikasi Manajemen Pegawai menggunakan teknologi HTML dan CSS.
    - Untuk menguji pemahaman anda, silahkan buat 2 halaman lagi yang berkaitan dengan data jabatan yaitu
        - `tabel-jabatan.html`, dan
        - `form-jabatan.html`
    - Sesuaikan jumlah input nya dan tabelnya sesuai kebutuhan.
    - Karena ada 2 file baru, ada baiknya ubah nama file berikut:
        - `tabel.html` menjadi `tabel-pegawai.html`
        - `form.html` menjadi `form-pegawai.html`
    - Karena terjadi penambahan file, sesuaikan juga link menu sidebar untuk masing-masing halamannya, pastikan jika diklik mengarah ke halaman yang benar.
    - Setelah semuanya selesai, jangan lupa lakukan `commit` dan `publish` project ke Github, serta deploy menjadi github-pages.
