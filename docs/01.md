# Persiapan Struktur Folder

- Buat repositori baru dengan judul semisal **apg-html**
- Buat file-file hhtml kosong dengan nama berikut:
    - `index.html`
    - `dashboard.html`
    - `tabel.html`
    - `form.html`
- Buat juga folder `css` dan buat file `style.css` di dalamnya
- Buat pula folder `images`, nantinya di sini kita akan menyimpan foto profil dan ikon/ brand aplikasi.
